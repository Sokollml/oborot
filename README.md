# Ступени — умный кредитный кабинет предпринимателя

Цифровой кредитный конвейер для малого бизнеса: подбор продукта, заявка, статус в реальном времени,
решение. Два кабинета — клиента и аналитика — над одной базой.

> Полная документация появится в фазе 5.

## Быстрый старт

```bash
cp .env.example .env   # необязательно: без .env используются значения по умолчанию
docker compose up --build
```

| Что | Адрес |
|---|---|
| Кабинет (вход для пользователя) | http://localhost:3000 |
| API, Swagger | http://localhost:8000/docs |
| Мок внешних сервисов | http://localhost:8001/docs |
