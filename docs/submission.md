## Тексты для формы сдачи

**Название:** Оборот — умный кредитный кабинет предпринимателя

**Одной строкой:** кредит для малого бизнеса онлайн — лимит без документов, заявка по ИНН и решение за минуты;
сложные заявки приходят специалисту с готовыми данными.

**Коротко (до 500 знаков):**
Оборот — цифровой кредитный конвейер для малого бизнеса. Клиент видит предодобренный лимит по оборотам счёта ещё
до заявки, подаёт её по ИНН (данные компании и выручка подставляются сами) и следит за статусом в реальном времени:
что происходит, сколько ждать, нужно ли что-то от него. Простые заявки система решает сама за секунды, сложные
получает специалист банка — с проверками, скорингом по факторам и рекомендацией. Каждое решение объяснено.

**Подробно:**
- **Клиент:** витрина и калькулятор, предодобренный лимит, подбор продукта за 3 вопроса, анкета в 4 шага
  с автосохранением, лента этапов и блок «Что дальше», одобрение / контрпредложение / отказ с причинами и советом,
  график платежей и ПСК до подписания, подпись кодом, «Мои кредиты» с графиком в Excel и расчётом досрочного
  погашения, переписка со специалистом, мобильная версия.
- **Специалист:** очередь «Ждут меня», карточка с проверками ЕГРЮЛ / ФНС / БКИ и сверкой выручки с оборотами,
  скоринг по факторам, рекомендация системы, решение с обязательным комментарием, аналитика конвейера.
- **Техника:** FastAPI + PostgreSQL + React; статусы меняются только через таблицу разрешённых переходов;
  очередь задач в PostgreSQL (`SKIP LOCKED`, аренда задачи, восстановление после падения воркера); идемпотентная
  отправка; скоринг на правилах из конфига с версией модели; внешние сервисы — мок с тем же контрактом.
  Запуск одной командой, только бесплатный open source, все данные синтетические. 143 автотеста и сквозная проверка
  всех сценариев в браузере — автоматически на GitHub (CI) при каждом изменении.
