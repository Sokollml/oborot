# Похожие продукты: что делают банки и что мы взяли

Обзор публичных материалов (октябрь 2026) о кредитовании малого бизнеса онлайн. Условия банков меняются;
мы смотрели не на ставки, а на **механику пути клиента**. Часть данных — с агрегаторов, это помечено.

## Общие паттерны рынка

1. **Банк уже знает клиента.** Обороты по расчётному счёту заменяют справки и выписки; клиенту на обслуживании
   показывают готовый лимит и просят меньше данных.
2. **Лимит до заявки.** «Сколько мне дадут» — первый вопрос предпринимателя; лидеры отвечают на него до анкеты.
3. **Минуты, а не дни,** для простых случаев; человек подключается только там, где нужен.
4. **Прозрачные условия до подписания:** ставка, полная стоимость, график, досрочное погашение.
5. **Всё в одном кабинете:** заявка, статус, документы, подписание, обслуживание кредита.

## Что из этого есть в «Обороте»

| Паттерн | Как реализовано |
|---|---|
| Банк знает клиента | Синтетические обороты по счёту в банке (модуль «АБС» в моке): выручка в анкете подставляется сама; специалист видит сверку заявленной выручки с оборотами. Компании без счёта (например, «Вектор-Тест») подтверждают выручку выпиской |
| Лимит до заявки | «Предодобренный лимит» на главной для компаний на обслуживании: сумма по продуктам, из чего сложилась, как увеличить, пересчёт по кнопке |
| Минуты для простых случаев | Автоматический конвейер: класс A по экспресс- и оборотному кредиту — одобрение без человека |
| Прозрачные условия | Предложение с ПСК, графиком платежей и основными условиями до подписания; после выдачи — карточка кредита со следующим платежом |
| Один кабинет | Заявка, статус в реальном времени, документы, переписка со специалистом, подпись, уведомления |

## Что сознательно не стали делать

- **Овердрафт и кредитную линию** — другая механика (лимит, погашение из поступлений), заметно расширяет объём.
- **Поручительство собственника** — юридически важно, но для демо добавляет экран без новой ценности.
- **Отсрочку по основному долгу** — меняет расчёт графика, оставили на следующий релиз.
- **Господдержку (льготные программы МСП)** — требует реальных правил программ.
